# CCTV — Hiseeu Linux & Home Assistant

Investigating a Linux-native, browser-based and/or Home Assistant interface for the Hiseeu D8208-5 NVR and 5522-F-Q PoE PTZ cameras, without requiring EseeCloud under Wine or obsolete Flash/ActiveX controls.

**Current state and confirmed technical findings:** [PROJECT_STATUS.md](PROJECT_STATUS.md)

The existing Home Assistant Generic Camera snapshot access must remain intact. NVR recording playback and PTZ API interoperability have not yet been verified.

The saved `IPCamera.tar.gz` camera webpage archive has **not** yet been published. It should be checked for credentials or private data before being added to this public repository.
